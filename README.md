# FunPay delivery and review bot

Небольшой бот для двух действий:

- после оплаты заказа отправляет покупателю ссылку `DOWNLOAD_URL`;
- после подтверждения заказа отправляет сообщение с ником покупателя, номером заказа и, при наличии, `review.png`.

Проект использует неофициальную библиотеку FunPayAPI. Её исходный код включён в папку `FunPayAPI/`, потому что опубликованный пакет PyPI 1.1.0 устанавливается некорректно. Версия взята из актуального репозитория [FunPayCardinal](https://github.com/sidor0912/FunPayCardinal); исходная библиотека распространяется по GPL-3.0, текст лицензии сохранён в `THIRD_PARTY_LICENSE_FUNPAYAPI.txt`.

FunPay может изменить внутренние методы сайта, поэтому сначала запускайте бот с `DRY_RUN=true` и проверяйте логи.

## Файлы

- `main.py` — точка входа Bothost;
- `FunPayAPI/` — локальная копия неофициальной библиотеки;
- `delivery_message.txt` — шаблон сообщения после оплаты;
- `review_message.txt` — шаблон после подтверждения;
- `review.png` — необязательная картинка, которую нужно добавить самостоятельно;
- `/app/data/orders.db` — база обработанных событий на Bothost.

В шаблонах доступны переменные `{buyer}`, `{order_id}` и `{download_url}`.

## Настройка Bothost

1. Платформа: Telegram.
2. Язык: Python.
3. Регион: Нидерланды.
4. Главный файл: `main.py`.
5. В поле Telegram Bot Token укажите токен отдельного пустого Telegram-бота. Код его не использует.
6. Добавьте переменные окружения:

```text
FUNPAY_GOLDEN_KEY=<секретная cookie FunPay>
DOWNLOAD_URL=<ссылка на скачивание мода>
DRY_RUN=true
SEND_REVIEW_IMAGE=true
DATA_DIR=/app/data
```

Сначала оставьте `DRY_RUN=true`. После появления в логах строки об успешной авторизации и проверки тестового события измените значение на `false` и выполните новый деплой.

## Проверка чата без покупки

Чтобы проверить получение и отправку сообщений без заказа, добавьте в Bothost:

```text
TEST_ALLOWED_USER=<точный ник тестового аккаунта FunPay>
TEST_COMMAND=<секретная строка, например !check-8f3a29>
```

Отправьте в чат с продавцом точное значение `TEST_COMMAND`. Бот ответит только нику из `TEST_ALLOWED_USER`. Этот ответ работает даже при `DRY_RUN=true`, но не отправляет ссылку на товар и не запускает запрос отзыва. После проверки удалите обе тестовые переменные.

## Безопасность

Не добавляйте `golden_key`, Telegram-токен или `.env` в GitHub. `golden_key` фактически предоставляет доступ к аккаунту FunPay. Репозиторий рекомендуется делать приватным.

## Ограничения

Гарантировать бесперебойную работу нельзя: официального публичного FunPay API для этого сценария нет. Сообщение отправляется только для системного события FunPay (`author_id == 0`), чтобы покупатель не мог имитировать подтверждение обычным сообщением.
